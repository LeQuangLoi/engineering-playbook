# Docker

Notes for building, running, and troubleshooting containerized workloads.

## Scope

Add Dockerfiles, Compose files, and operational notes here when there is a concrete workflow to document. Create the matching subfolder only when the first related artifact is added; avoid empty placeholder directories.

Each reusable workflow should have a focused Markdown page covering prerequisites, commands, validation, and cleanup. Keep secrets, local credentials, and environment-specific values out of examples.
