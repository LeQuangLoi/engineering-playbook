# Certificate Exam

Study material and personal notes for Azure certification preparation.

## Contents

- [Azure AZ-104 study file](Azure-AZ104.docx): Original study material.

Temporary Office files such as `~$*.docx` and `~*.tmp` are local editor artifacts and are not part of the playbook structure. Do not link to or commit them.

## Study Note Rule

When adding personal learning experience, create a Markdown page beside the source material. Use this shape:

1. **Topic**: The Azure service or exam area.
2. **Key Concepts**: The facts to remember.
3. **Hands-on Practice**: Commands or portal steps using safe placeholders.
4. **Common Mistakes**: Errors and how to avoid them.
5. **Related Topics**: Links to Azure or Kubernetes notes in this repository.

Keep original reference files as source artifacts and put your own explanations in `.md` files.
