# PowerShell Automation

General PowerShell automation that is not specific to SOPS or another technology component.

## Placement

Use this folder for reusable PowerShell workflows, modules, and operational helpers. Keep each script beside a Markdown page that documents its purpose, parameters, prerequisites, output, validation, and risks.

Technology-specific PowerShell belongs in the owning component, such as `Azure/` or `Kubernetes/`.
