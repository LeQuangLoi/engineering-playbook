# PowerShell

PowerShell automation and Windows engineering notes.

## Contents

- [SOPS](Sops/README.md): Secret encryption and decryption workflows.
- [Automation](automation/README.md): General PowerShell automation workflows.

## Scope

Use this folder for PowerShell-specific workflows, modules, and operational helpers. Use [Script](../Script/README.md) only for shell automation grouped by execution environment.

Place reusable scripts beside a Markdown page that explains their parameters, prerequisites, and safe usage. Keep credentials and decrypted files out of the repository.
